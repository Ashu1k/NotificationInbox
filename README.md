# Android Notification Inbox

An Android application developed using Java and XML.

## Technologies Used
- Java
- XML
- Firebase Cloud Messaging (FCM)
- SQLite Database
- Glide Image Loading
- Android Notifications

## Features
- Receive push notifications using Firebase Cloud Messaging.
- Store notifications locally using SQLite.
- Display notification title, description, image and timestamp.
- Track read and unread notifications.
- Open notification details by clicking an inbox item.
- Handle duplicate notification IDs.

## Project Setup
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Configure your own Firebase project.
4. Add your `google-services.json` inside the `app` folder.
5. Sync Gradle and run the application.
